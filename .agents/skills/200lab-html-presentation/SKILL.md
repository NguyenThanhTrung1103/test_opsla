# 200Lab HTML Presentation Generator

Transform Markdown audit findings and architectural assessments produced by 200Lab skills into an interactive, self-contained HTML dashboard.

> [!NOTE]
> **Provenance Disclosure**: This is a **local presentation helper skill**. It formats and visualizes findings collected from other 200Lab skills; it is not a direct upstream capability of the 200Lab MCP server.

## Scope & Security Boundaries

- **HANDLES**: Generating offline-capable, standalone HTML reports with Tailwind/CSS styling, finding filters, and Mermaid.js diagram rendering.
- **DOES NOT HANDLE**: Modifying application source code or running web tracking scripts.
- **SECURITY**: Generates self-contained static HTML without external telemetry or data transmission.

---

## Execution Workflow

### Step 1: Ingest Audit Findings
- Read Markdown reports generated by `200lab-system-design`, `200lab-backend-reliability`, or `200lab-technical-review`.
- Extract finding counts (Critical, High, Medium, Low), code snippets, and file paths.

### Step 2: Assemble Dashboard Features
The generated HTML dashboard includes:
1. **Summary Banner**: Total findings, maturity score, and audit timestamp.
2. **Interactive Filters**: Instant filtering by severity (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`) and category.
3. **Finding Cards**: Expandable cards displaying location links, code diffs, root cause analysis, and remediation steps.
4. **Mermaid.js Integration**: Embedded architecture diagrams rendered client-side via Mermaid CDN.

### Step 3: Write Output File
- Save the dashboard to `docs/reports/200lab-audit-dashboard.html` or the user-specified destination.
- Provide a file URI link so the user can open it directly in their default browser.
