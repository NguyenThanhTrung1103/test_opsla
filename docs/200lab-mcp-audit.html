1. Đối Chiếu Kiến Trúc Repository với Năng Lực 200Lab

Hiện trạng Repository (Oops La Bookstore):
  • Frontend: Vanilla ES Modules + Tailwind CSS (Claude Design Tokens) tại oops_la_book_store_uxui_fixed.html → dist/index.html.
  • Backend: Node.js Native HTTP server thuần túy (`src/server/app.ts`), không dùng Express/NestJS, zero-dependency.
  • Storage: IndexedDB Adapter giả lập trình duyệt và lưu bền vững vào `data/oopsla-storage.json`.
  • Invariants Cốt lõi: AC-11 (Duyệt đơn chỉ dành cho Owner), AC-15 (Trừ kho 1 lần), OD-01 (Chặn Staff hủy đơn đã chốt), BD-04 (Zero auto-decrement), CURR-01 (100% VNĐ).
Năng Lực Trọng Tâm của 200Lab MCP:
  • Backend Reliability Review: Rà soát timeout, retry, idempotency, race conditions và deadlocks.
  • Systematic Debugging: Thiết kế regression test, bóc tách root cause và chứng minh bằng log.
  • Diagram Director: Vẽ sơ đồ kiến trúc động (animated HTML/SVG) trực quan không cần cài thêm công cụ.
  • System Design & Scaling: Đánh giá ranh giới module, chiến lược chuyển từ JSON storage sang PostgreSQL/SQLite khi mở rộng.
